# Textbook design

- Write objectives a reader can check: "explain", "compare", "solve", "give an example of". Avoid "understand" and "appreciate".
- Each chapter serves its objectives. Every section should move a reader toward one of them; cut what does not.
- Order chapters from concrete to abstract. Introduce a term before using it, and define it where it first appears.
- Match the reading level: short sentences, one idea per paragraph, examples from the readers' everyday life.
- Discussion topics invite thinking, not recall: "Why might...", "What would change if...". Anchor each to the sentence it extends, and spread them across the chapter.
- State facts you are sure of. Mark anything uncertain for the fact-check story instead of guessing, and never cite a source you have not read.
- Illustrations explain something the text cannot; decorative images cost money and add nothing to learning.
- Provided text (content source provided) is the author's. Copy it as written; report gaps, errors and limit problems to the author instead of fixing the wording.
