# Textbook learning features

Textbooks, lesson plans and classes share one learning workflow. Cite the exact
textbook section for every plan objective, question, expected answer and factual
claim. A model response is not a source. Record original author, title, edition,
source locator, licence and third-party exceptions in an appendix. Keep AI-written
explanations distinct from source evidence. In upubhub, a Teacher can also build
an editable plan from selected textbook sections, review quoted primary points,
and explicitly attach its assignments to a class. These are reviewed actions,
not automatic side effects of importing or pushing files.

Chat-outs are named topic links, with editable background about the selected
text, source citations, terms, assumptions and suggested deeper questions. Their
label is displayed by upubhub; a template does not add emoji markers or interface
code to the manuscript. Class exploration records participation only when opened
through an assessed assignment. Assessment questions and grading evidence must
come from the assigned published text. State the configured question/round count,
attempt limit and grading strictness. AI grades remain provisional for teacher
review; question count alone is not comprehension. Paste restrictions deter
copying but do not prove a student worked without outside AI.

Interactive learning visuals are a separate feature under implementation in
upubhub. Do not claim they are already deployed or emit an unsupported payload.
When requested, describe the desired model/chart, teaching purpose, defaults,
units, data snapshot, original source, transformations, limitations, reset and
chat-out background in docs/project/learning-visuals.md for human review. Do not
create executable scripts or fabricate statistical data. Only use a typed visual
block after the published upubhub contract and this dashboard's validator both
support it. Otherwise keep the reviewed specification as a handoff; the normal
push uses the existing format. New visual code is not part of a content project.

For supplied manuscripts, preserve the author's exact wording and existing valid
links/attribution. Report unsupported blocks and missing evidence to the author
instead of deleting them, rewriting them or silently dropping them on push.
Nothing is published, assigned, assessed or sent to a provider without the
applicable human review and the existing explicit workflow.
