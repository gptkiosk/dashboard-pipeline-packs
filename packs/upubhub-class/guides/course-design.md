# Course design

- Write objectives a teacher can check: "explain", "compare", "solve", "give an example of". Avoid "understand" and "appreciate".
- Each lesson serves its objectives. Every section should move a student toward one of them; cut what does not.
- Order lessons from concrete to abstract. Introduce a term before using it, and define it where it first appears.
- Match the reading level: short sentences, one idea per paragraph, examples from the students' everyday life.
- Discussion topics invite thinking, not recall: "Why might...", "What would change if...". Anchor each to the sentence it extends.
- Lesson plans: objective, warm-up, reading, discussion, check for understanding, timing. Note what to watch for when students struggle.
- Assessment settings follow the objectives. Weight reasoning or application higher when the lesson is about explaining or using an idea.
- State facts you are sure of. Mark anything uncertain for the fact-check story instead of guessing, and never cite a source you have not read.
- Illustrations explain something the text cannot; decorative images cost money and add nothing to learning.
