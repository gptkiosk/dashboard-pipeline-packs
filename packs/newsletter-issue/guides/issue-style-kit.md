# Issue style kit

Art matches an issue when every picture is built from the same few decisions. Write them once in `media/style-kit.md` and reuse them word for word.

- Look: medium and finish, for example "digital painting, soft brushwork, clean edges".
- Palette: the accent colour from the settings, two supporting colours and a light or dark ground.
- Light and mood: one sentence, for example "warm directional lamp light, calm".
- Cast: any recurring character or object, described the same way each time.
- Avoid: text in the picture, logos, real people, anything that conflicts with the look.

If the operator supplies reference images, the style kit describes what they share and each prompt names the same reference. Each prompt is the style kit plus one scene. The header scene shows the issue's subject; inline scenes show one idea each.
